## Corrected behaviors
- Active page managers can edit existing profile content and logos. They cannot create a business/profile, reassign its business, or submit a review.
- Owners/admins can revise approved/pending profiles; existing approved snapshots remain a backend responsibility. Suspended profiles stay blocked.
- Profile links are edited and saved as the full ordered website/menu/product/other collection, up to the backend limit of 20.
- Profile editor and inbox content are remounted per selected organization, preventing old organization data/actions from persisting across switches. Asynchronous auth membership resolution uses the same ID for inbox reads and actions.
- Public Directory exposes category/state/city/region/verified filters, displays public legal/DBA/location/category/license identity and all safe links, and resets its opaque cursor/results when filters change. Loading more cannot merge another filter's rows.
- The shared membership type and organization parser accept page_manager without granting organization administration.
